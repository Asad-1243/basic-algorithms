## How this repo works

1. Copy `template.py` into the topic folder, for example `sorting/bubble_sort.py`.
2. Write the algorithm and its tests.
3. Run it:

   ```bash
   python sorting/bubble_sort.py
   ```

4. Tick the box above and commit:

   ```bash
   git add .
   git commit -m "Add bubble sort"
   git push
   ```

No packages to install, just Python 3.
